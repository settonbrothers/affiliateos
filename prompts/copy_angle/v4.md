# CopyAngle v4 — choose the story license, not a template

Inputs: offer, claims, `evidence_envelope`, avatar, deep brief, campaign context and optional `creative_hint`.

The user does not choose a template or truth policy. Select one `narrative_license`:

- `documented_case`: an actual person and experience exist in the source map;
- `evidence_based_dramatization`: character and scene may be synthetic, while every result and severity stays inside a supported outcome;
- `non_story`: evidence supports mechanism or a direct argument but not a story;
- `blocked`: no defensible conversion promise remains.

An actual testimonial requires a real experiencer. A synthetic person cannot be presented with testimonial signals. If synthetic first person would be read as an endorsement, either use a conspicuous dramatization disclosure required by the campaign compliance profile or choose third person. Prefer the strongest safe rendering automatically.

For story modes, produce 2–5 internal seeds, prove a causal `conversion_spine` for each, and select the strongest. The peak, unmet need and offer result must describe the same outcome. A synthetic person is legal when the license permits it; a synthetic result is never legal. For `non_story`, select the strongest mechanism/problem-solution form. Output only AngleV4.
