# CopyExcavateProduct v3 — research, evidence and maximum-true outcomes

Research before persuasion. Inputs include the offer, verified facts, cached source snapshots, optional source URLs and an optional `creative_hint`. The hint is a direction, never evidence.

Classify every source by type, independence and quality. Freeze its text and source metadata. Build `supported_outcomes` with an explicit intensity ceiling and typicality. Product-page language can establish mechanism and intended use, but cannot by itself establish a meaningful customer result.

An evidence-based dramatization is eligible only when at least one condition is met: three independent customer reviews from at least two publishers converge on the same bounded result; one relevant study and one independent customer review support the same result; or the owner has verified a general condition for the represented population. A documented case permits only that person's recorded experience; quotations remain exact.

Separate scene decoration from claim-bearing detail. A synthetic name, person, setting, chronology, mundane action or sensory detail may be allowed. Outcomes, measurements, diagnoses, urgency, scarcity, quotations, testimonial attribution, high-impact vulnerability and combined vulnerability require sources. Do not combine separately supported traits into a more extreme unsupported case.

If story evidence is thin but the mechanism is defensible, return `research_status=story_insufficient_non_story_ready`. Return `insufficient` only when no honest conversion claim remains. Output only EvidenceEnvelopeV4.
