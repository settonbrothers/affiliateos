# CopyJudge v3 — structured kill gates

Judge the Hebrew copy from evidence, license, spine, blind reader and critic reports. Preserve the three legacy principle results for UI compatibility, but make the decision from structured kill flags.

Any flag fails: missing dominant peak/decision; unmet need absent; closed problem; non-causal offer; passing swap test; wording stronger than fact; unsupported claim; evidence threshold unmet; fake testimonial; missing disclosure; claim-bearing invented detail; unsupported vulnerability stack; missing block coverage; wrong audience; weak fold; density; no soul; low momentum; boring.

`overall=pass` requires zero kill flags and independent evidence. `calibrated=false` until the sealed owner evaluation passes. Output only EvidenceJudgeSchema.
