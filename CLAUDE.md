## Hard Rules
- **Branching**: feature branches (`feat/m1-...`); never push directly to `main` once branch protection is enabled. Rebase only — no merge commits.
- **TypeScript**: never `any`; use `unknown` + narrow. Project is strict + `noUncheckedIndexedAccess`.
- **Forms**: React Hook Form + zodResolver. **API/agent boundaries**: validate with Zod.
- **Supabase access**: only through `src/lib/supabase/{client,server,admin}.ts` — no ad-hoc `createClient`.
- **DB rules**:
  - All migrations admin-coordinated (ask before adding).
  - New tables ship RLS in the same migration.
  - Don't regenerate `database.ts` from a feature branch — regen on `main` after merge.
- **Forbidden packages**: Drizzle, Prisma, tRPC, Redux, Zustand, LangChain.
- **Secrets**: `.env.local` is gitignored — never commit it; never paste secrets into code or chat. `SUPABASE_SERVICE_ROLE_KEY` is server-only (`admin.ts` uses `import 'server-only'`).
- **Edge fn deploys**: should move to CI before regular use; until then, a manual `supabase functions deploy` is acceptable (note in PR).
- **Shared-contract changes ship together.** An edge function WRITES `ai_runs.output_payload`; the Next app READS it. They deploy independently, so changing the shape and deploying only the writer takes the site down — that is exactly how the offer page died once (`{score, reasoning}` rendered where a number was expected → "Objects are not valid as a React child"). Deploy the function *and* `vercel --prod` in the same pass, and make the reader tolerant of both shapes (`Stored*` schema + a `normalize*` helper) so the next one degrades instead of crashing.
- **Prompt versions**: `prompts/<name>/_active.json` declares which version should be live. `pnpm prompts:sync` reports DRIFT and exits non-zero; it never flips a live prompt as a side effect. Use `pnpm prompts:activate` or `/admin/prompts` deliberately. R5 (>75% golden-set agreement before shipping a prompt) cannot currently be honoured — there are no labels — so say so rather than implying a prompt was measured.
- **Don't ask a model to compute a mechanical rule.** If a field is derivable (`recommended` = all filters pass AND score ≥ 55), derive it. Models get deterministic booleans wrong, and the audit found real cases.

## Windows / dev gotchas
- After switching branches, clean the stale Next build cache: `Remove-Item -Recurse -Force .next` — Next leaks route validator types across branches and `tsc` complains.
- PowerShell `>` redirect writes UTF-16 (breaks TS files). Use `| Out-File -Encoding utf8`.
- Supabase CLI: use `pnpm dlx supabase@latest <cmd>` — `winget` does not carry a `Supabase.CLI` package; the npm/dlx route is documented and avoids a global install.
- Never edit files under a `[id]` path with PowerShell — the bracket glob truncates them. Use the editor tools.
- In a `.mts` script, end with `process.exitCode = n`, not `process.exit(n)`: exiting with handles still open trips a libuv assertion on Windows.
